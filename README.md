## Como trabalho

1. Processo e regra de negócio antes do editor  
2. Banco e permissões pensados juntos (RLS, triggers, RPCs)  
3. Regra crítica no backend — não só na tela  
4. Automação com falha definida: quando quebra, vai para humano e fica registrado  

Formação em engenharia de processos (ULBRA + MBA PUCRS). Uso Cursor/Claude para acelerar; reviso arquitetura antes de subir.
